# -estacao-espacial-orbit


Projeto de simulação do fluxo de desenvolvimento corporativo em camadas.

## Camadas do ambiente

- **develop**: ambiente de desenvolvimento, onde novas funcionalidades são implementadas.
- **stage**: ambiente de testes/homologação, onde as mudanças são validadas antes de ir para produção.
- **main**: ambiente de produção, código estável e revisado.
